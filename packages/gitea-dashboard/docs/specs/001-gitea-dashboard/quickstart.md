# Quickstart: проверка Gitea Dashboard

## Предпосылки
- Chrome ≥ 120, Node 22, pnpm.
- Личный токен в `https://git.sadmin.app/user/settings/applications` с правами `read:repository, read:issue, read:user, read:organization, read:notification` (см. contracts/gitea-api.md).
- Для проверки деградации — второй токен без `read:organization`.

## Сборка и установка
```bash
pnpm install
pnpm test          # юнит + интеграция (fakeBrowser)
pnpm build         # .output/chrome-mv3
pnpm zip           # .output/gitea-dashboard-<ver>-chrome.zip
```
`chrome://extensions` → «Режим разработчика» → «Загрузить распакованное» → `.output/chrome-mv3`.

## Проверка безопасности (SC-007)
- `chrome://extensions` → service worker → DevTools → Console: `chrome.storage.sync.get(null)` — токена нет; `chrome.storage.local.get(null)` — токен только в `token:*`.
- Прогнать Q3/Q5 и просмотреть консоль фона и окна: токена нет ни в одном сообщении.
- DevTools → Network фона: запросы только к `git.sadmin.app`.

## Нагрузка (SC-009)
Network фона за 5 минут без открытого окна: ≤ 100 запросов (org-режим). Записать фактическое число в README.
